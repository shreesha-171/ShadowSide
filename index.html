Shadow Side

Shadow Side is an interactive routing and solar-tracking system designed to calculate real-time sunlight exposure and shadow distribution during road travel. By combining route geometry with solar position data, the app precisely estimates travel durations spent under left, right, and overhead sunlight, helping travelers plan more comfortable and efficient journeys.

Key Features

  • Solar Exposure Breakdown: Time-weighted analysis (hours/minutes) showing the percentage of sunlight vs shadow exposure on both sides.
  • Interactive 8-Point Compass: Real-time map-based compass (N, NE, E, SE, S, SW, W, NW) with a dynamic solar position indicator ☀.
  • Live Hardware Tracking: GPS integration with device orientation sensors (DeviceOrientation API) for real-time compass rotation.
  • Alternative Route Selection: Multi-route engine enabling users to toggle between fastest highways and shorter alternatives.
  • Arrival & Night Detection: Predicts arrival times and automatically detects nighttime journeys (before sunrise or after sunset).
  • On-Map Visual Legend: Color-coded overlays showing solar positions along the route in real time.

Technologies Used

  • Leaflet.js -> Map rendering & custom UI controls
  • OpenStreetMap (France & Esri) -> Base map tile services
  • OSRM Routing API -> Live multi-route generation
  • Nominatim API -> Geocoding & coordinate search
  • SunCalc.js -> Astronomical solar position & time calculations
  • DeviceOrientation & Geolocation APIs -> Real-time motion and compass tracking
